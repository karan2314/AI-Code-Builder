# Fraud Benchmark & Evaluation

## Rule zero

Numbers shown anywhere come only from `docs/metrics/*.json` generated by these scripts. Never
estimate or round up. If a metric isn't measured, leave it out.

## `evals/run_benchmark.py`

1. Load the test split (days 76–90) with labels.
2. A: rules_score ≥ rules threshold (calibrated on val). B: blended ML ≥ threshold.
3. Per variant: precision, recall, PR-AUC (`average_precision_score`), FP/10k, candidate rate,
   fraud value captured (sum of the fraud amount detected / total fraud amount), P50/P95 batch latency per txn.
4. D: sample N candidates from B (e.g. 30, stratified fraud vs non-fraud) + golden scenarios; run the real
   investigation; measure tier-vs-label agreement (Tier ≥ 2 counts as "flag"), evidence validity rate,
   invalid citations, P50/P95 investigation latency, average input/output tokens.
5. **Gemini escalation rate** = investigated / screened. **Cost per 1,000 txns** = (screening compute
   ≈ Cloud Run vCPU-seconds × price) + (escalation rate × 1000 × avg tokens × Gemini price per token).
   Put the price constants in `evals/pricing.yaml` with a source URL and date. Show the formula in the JSON.
6. C* (optional): only if `ENABLE_JEV=true` and a key exists; same data; otherwise `"status": "not_run"`.
7. Write `docs/metrics/benchmark.json` and `agentic_eval.json`:
   `{generated_at, dataset_seed, model_version, policy_version, prompt_version, gemini_model, variants:{A:{…},B:{…},C:{…},D:{…}}}`.

## Golden scenarios (`evals/scenarios/*.json`)

hero_ato (expect Tier 3, must cite device_novelty + velocity + known_fraud_link), benign_high_value (Tier ≤ 1),
mule_network (Tier ≥ 2), card_testing (Tier ≥ 2), limited_history (`requires_review`), tool_failure (an `unavailable`
item is present and the summary lists it in missing_evidence), stale_link (not R1).

## Verify

The scripts run end to end, the JSON validates against the schema, `/api/metrics` serves it, and the numbers in the README/deck
match the JSON (the `submission-metrics-check` hook checks this).
