## Conventions

- Layering: `api` → `cases`/services → `agents` → `tools` → `features`/`ml`/`graph`/`data`.
  Tools never call Gemini. The policy engine never calls Gemini.
- Every tool: typed signature, docstring (ADK uses it), returns a Pydantic model that converts to `Evidence`.
- IDs are prefixed: `TXN-`, `CUST-`, `ACC-`, `DEV-`, `MER-`, `CASE-`, `EV-`.
- API routes are prefixed `/api`. `GET /healthz` is unauthenticated.
- Python: snake_case, type hints everywhere, ruff clean. TS: strict mode, PascalCase components.
- Generated data and model artifacts are reproducible from seed (`--seed 42`) and gitignored (except small fixtures).
